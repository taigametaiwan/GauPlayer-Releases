# Gấu Player — Bản phát hành

Kho phân phối APK chính thức cho Gấu Player Mobile và Android TV.

## Tải ứng dụng

Xem [các phiên bản đã phát hành](https://github.com/taigametaiwan/GauPlayer-Releases/releases). Mỗi phiên bản có 5 APK riêng: Mobile ARM32, Mobile ARM64, ATV ARM32, ATV ARM64 và ATV x86_64.

## Cập nhật trong ứng dụng

Từ phiên bản có hỗ trợ OTA, vào **Cài đặt → Kiểm tra cập nhật ứng dụng**. App tải nguyên APK phù hợp, xác minh file và mở trình cài đặt Android. Android có thể yêu cầu cấp quyền và xác nhận cài đặt.

Mỗi release kèm `update.json` có chữ ký và `SHA256SUMS.txt`.

Kho này chỉ chứa bản cài đặt và thông tin cập nhật; không chứa mã nguồn riêng, API key của người dùng hoặc khóa ký riêng.
